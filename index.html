Como conectar ao Supabase (apenas front-end)

O frontend pode conter APENAS:

  • Supabase Project URL (ex.: https://xyz.supabase.co)
  • Supabase publishable key / anon key

NUNCA coloque service_role, secret keys ou tokens administrativos aqui.
